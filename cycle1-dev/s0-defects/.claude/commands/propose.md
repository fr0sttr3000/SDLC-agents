description: Подготовить Proposal v1 для подтверждённых известных ошибок
---

Для Project `$ARGUMENTS` подготовь только Proposal v1 TSV по `_contract/MEMORY_V1.md` в
явно заданный пользователем output path. Источники — current `tracking/known-issues.md` и
verified S5 defect artifacts. Не применяй proposal, не обращайся к provider и не создавай
approval. Если output path не задан, заверши `BLOCKED` без записи.
